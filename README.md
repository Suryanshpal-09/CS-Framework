## 📌 What is CS Framework?

**CS Framework** is a self-paced learning roadmap designed to bring a broad, degree-style Computer Science curriculum together with practical software development and AI engineering.

Learning CS often means jumping between university lectures, tutorials, documentation, practice sites, and project ideas. CS Framework aims to give that learning a clearer path: study a concept, use high-quality free resources to understand it, check your knowledge, and then apply it in something you build.

The roadmap follows a **fundamentals-first, build-first approach**. It starts with programming and developer tools, moves into web applications and AI-powered products, explores how computers work under the hood, and then advances through mathematics, machine learning, systems, cloud, security, and a capstone project. Core theory can run alongside practical work rather than being left until the end.

**The goal is not just to collect tutorials. It is to become capable of understanding, building, testing, and explaining real software.**

## 🧭 How the learning path works

The framework is organised into six stages. The four year-based stages are complemented by a common starting section and an industry layer.

|Stage|Subjects|Focus|
|-|-:|-|
|**Start here**|2|Programming fundamentals, developer tools, and how the internet works|
|**Year 1**|6|Mathematics, programming design, data structures, and digital logic|
|**Year 2**|7|Algorithms, computation theory, computer architecture, operating systems, databases, and systems programming|
|**Year 3**|7|Compilers, security, machine learning, networking, distributed systems, software engineering, and concurrency|
|**Year 4**|8|Deep learning, computer vision, advanced algorithms, cloud, graphics, embedded systems, product thinking, and a capstone|
|**Industry layer**|6|Full-stack development, backend APIs, generative AI engineering, system design, interview practice, and professional skills|
|**Total**|**36**|A broad CS learning roadmap with practical engineering and AI topics|

### A recommended learning loop

1. **Learn:** open a subject and work through its listed concepts.
2. **Explore:** use its videos, articles, books, and official documentation to deepen your understanding.
3. **Practise:** attempt the linked quiz, problem set, interactive lab, or other self-assessment where available.
4. **Build:** apply the concept in an exercise or project rather than relying on passive watching alone.
5. **Review:** mark the subject complete when you can explain the key ideas and use them without following a tutorial step by step.

The study order and weekly estimates are guidance, not deadlines. Adjust them to your existing knowledge, available time, and desired depth.

## 🛠️ Project pathway

The roadmap encourages learners to turn study into a portfolio of understandable, well-documented projects. The items below are **project ideas and learning targets**, not a statement that all of them are already implemented in CS Framework.

### 1\. Make things

* Command-line to-do app in Python
* File organiser and web scraper
* C versions of utilities such as `wc` and `grep`
* Object-oriented library-management system
* A GitHub profile and README for each project

### 2\. Build real products

* Portfolio site with HTML, CSS, and JavaScript
* Pixel-accurate React clone of an existing app interface
* Full-stack notes application using Next.js, PostgreSQL, and authentication
* Real-time chat with WebSockets
* REST API with tests and documentation, or a URL shortener
* **ChatGPT-style AI chat application with streaming and conversation memory**
* **Retrieval-Augmented Generation (RAG): chat with your own PDFs and notes**
* A mini Cursor-style AI code editor as a stretch project

### 3\. Understand the machine

* Build a computer from NAND gates to a CPU with Nand2Tetris
* RISC-V assembly programs, such as Fibonacci and sorting
* Your own shell and a basic memory allocator in C
* Multithreaded web server in C
* TCP chat using sockets and packet analysis with Wireshark
* Key-value database using an append-only log

### 4\. Math and intelligence

* Matrix library and PCA from scratch
* Linear and logistic regression from scratch
* A small automatic-differentiation engine
* MNIST classifier in PyTorch
* Train a small GPT model on your own text
* Object-detection demo and a reinforcement-learning agent for a simple game

### 5\. Scale and ship

* Add Docker and CI/CD to previous applications
* Deploy an application behind a load balancer on AWS
* Build a distributed key-value store using Raft
* Monitoring dashboard with alerts
* Security audit of OWASP Juice Shop
* Capstone: ship a product and gather feedback from real users

### Always-on practice

* Implement a data-structures library
* Work through Easy and Medium algorithm problems over time
* Build an interpreter for a small language
* Create a ray tracer
* Build an Arduino or ESP32 project
* Write regularly about what you learn

## 🖥️ Using the website

### Explore the roadmap

* Select a curriculum filter to view all subjects or focus on gaps, partial coverage, or already-covered topics.
* Select a subject card to reveal its topic outline, recommended sequence, relevant resources, tools, and completion guidance.
* Use the **Study order** section to review the phase sequence and estimated effort.
* Open **Tools** and **Projects** to see the technologies and project ideas grouped by learning phase.

### Track your progress

* Tick a subject's checkbox when you have completed it.
* Use the progress bar and completion count to review your overall progress.
* Progress and theme preferences are saved in your browser using local storage. They are browser-specific; they do not automatically sync across devices or browsers. Clearing website storage can remove the saved state.

### Personalise the study plan

* Set the number of hours you can study in a typical week.
* Adjust the learning-depth multiplier to make the estimated plan leaner or more thorough.
* Select a week to see the subjects scheduled for that part of the plan.

The estimates are intended as planning aids, not promises about how quickly someone can complete the curriculum. The website deliberately leaves interview preparation optional until it becomes relevant to a learner's goals.

## 🚀 Run locally

The attached newer version is a **standalone HTML page** built with HTML, CSS, and vanilla JavaScript. It does not require a Node.js build step or a package installation to open.

### Option A — open the HTML file

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.

### Option B — serve it locally

A local HTTP server can be useful for testing the page in a browser:

```bash
git clone https://github.com/suryanshpal808-rgb/CS-Framework.git
cd CS-Framework
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

The page uses browser features such as `localStorage` for progress and theme preferences. It also loads its selected fonts from Google Fonts when network access is available; the rest of the page is in the HTML file.

## 🤝 Contributing

Ideas, bug reports, typo fixes, curriculum suggestions, and high-quality free learning resources are welcome.

1. Check the existing repository issues or open one to discuss a substantial change.
2. For resource suggestions, include the subject, resource title, link, language, and why it is useful.
3. For code changes, keep the page usable on smaller screens and test the relevant interactions.
4. For curriculum changes, prefer reputable resources, clear learning outcomes, and exercises that help learners check their understanding.
5. Do not commit API keys, access tokens, passwords, or other secrets.

To contribute, fork the repository, create a branch for your change, commit your work, and open a pull request describing what changed and how it was tested.
